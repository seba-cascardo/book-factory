- `backup-book-factory-v2.4.3/`: the installed v2.4.3, saved on 2026-07-03 before the v3 redesign.
- `book-factory.skill-workspace/`: the eval set used while building v3 with skill-creator.

The design briefs behind v3.0 and v3.4 are in `docs/`. The audits and reviews they cite live in `docs/reviews/`, which is kept out of this public repo.
